# Independent App Support Platform

## Current foundation

- **Hosting:** GitHub Pages, which is already live and free.
- **Public address:** `https://slotmachinebuddy.github.io/slot-machine-buddy-support/`.
- **Privacy:** static HTML only; no analytics, advertising, scripts, forms, or user accounts on the site.
- **Current app:** Slot Machine Buddy remains available at a stable on-page section so its existing in-app support and privacy link continues to work.

## Near-term implementation

1. Maintain a neutral support-home page with one card per app.
2. Give every app its own clearly labelled troubleshooting, privacy, and policy-change sections.
3. Use the private support email for user contact and clearly warn users not to send sensitive information.
4. Update each app policy and support page before directing users to the address.

## Generic email recommendation

The dedicated support address is `independentappsupport@proton.me`. It is neutral across apps and does not include a personal name or the Slot Machine Buddy brand. Protect it with a password manager and two-factor authentication. The public site and in-app policy are the official support routes.

## Future upgrade path

If the number of supported apps grows, create a neutral GitHub organization and Pages repository with a generic address. A custom domain can later replace the GitHub Pages address, but it adds a recurring domain-registration cost. Neither a custom domain nor a paid host is needed for the current support site.

## Adding an app

For each new app, add an app card, an app-specific policy section, a troubleshooting checklist, and a review date. Confirm the app's in-app support URL, App Store privacy declaration, and public policy say the same thing before publishing.
